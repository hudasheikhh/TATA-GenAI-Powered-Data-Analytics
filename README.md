# 🚀 Tata Data Analytics Virtual Internship 2025

## AI-Powered Collections Strategy for Geldium

This project focuses on predicting customer delinquency risk using a **Random Forest Classifier** and designing an AI-powered collections strategy for Geldium.

---

## Project Highlights
- Performed Exploratory Data Analysis (EDA)
- Identified key delinquency risk factors
- Built a predictive modeling framework
- Designed an AI-powered collections workflow
- Applied Responsible AI principles

---

## Model Used
### Random Forest Classifier
The model predicts whether a customer is likely to become delinquent based on financial and behavioral features.

### Top Features
- Credit Utilization
- Missed Payments
- Debt-to-Income Ratio
- Credit Score
- Income

---

## Key Findings
- High credit utilization (>50%) increases delinquency risk
- Customers with multiple missed payments are higher risk
- Missing values identified in Income and Loan Balance columns
